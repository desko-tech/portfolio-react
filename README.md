# Personal Portfolio

This is a small, modern, React-based personal portfolio that showcases some of my skills and experiences as a developer. It was built with a focus on clean design, responsive layouts and a simple user experience, using Copilot and GPT-5.6 Luna.

## ✨ Features
- 🎨 Clean and modern UI
- 📱 Fully responsive design
- ⚛️ Built with React
- ⚡ Powered by Vite
- 🧩 Component-based architecture
- 🚀 Deployed with GitHub Pages


## 🛠️ Tech Stack
- React — UI library
- Vite — Development & build tooling
- JavaScript — Application logic
- CSS — Styling & responsive design
- GitHub Pages — Deployment
